## Question

Що саме будуємо, для кого, на чому, і в якому порядку. Пункт призначення мапи залежить від цього.

## Answer

Прийнято в сесії 2026-11-05, Артем попросив обрати за нього.

- Для себе, потім для друзів, потім публічно. Паралельно шоукейс для резюме.
- Форма: окремий публічний репозиторій-плагін для Claude Code, робоча назва packloom. Скіли плюс
  Python-скрипти. Без MCP і без власного лаунчера. Techpack стає першим споживачем.
- Python, бо build.py, smoke-test.py і генератор квестів уже на ньому.
- Minecraft 1.20.1 Forge, як у техпаку.
- Свій build.py замість Packwiz; Packwiz повертається лише коли друзям знадобиться автооновлення.
- Серверний smoke-тест як єдиний автоматичний цикл перевірки; клієнтські краші читаються з логів Prism
  після ручного запуску.
- Java-моди поза скоупом; інтеграція тільки текстом: датапаки, конфіги, FTB Quests.
- Агент як помічник: пропонує і резолвить, фінальні рішення за Артемом.
- Одиночна гра спочатку, VPS-сервер для друзів окремим зрізом.
- Порядок зрізів: 1) репозиторій і перенос build/test з техпаку; 2) клавіатура з options.txt;
  3) HTML-шпаргалка; 4) деплой сервера.
- Стан середовища: на Mac не встановлені Prism і Java runtime.
