# Назва репозиторію і наратив README для резюме

Type: grilling
Status: resolved
Blocked by:

## Question

Обрати остаточну назву (робоча packloom; перевірити, що не зайнята на GitHub і PyPI), і написати перший
абзац README: що це, для кого, чим відрізняється від лаунчерів і від ModSmith. Результат: назва і README-абзац
англійською, плюс рядок для резюме.

## Answer

Назва: **packloom**. packwright зайнята на PyPI і GitHub (зокрема Minecraft-модом Packwright від oliviathevampire).
packloom вільна на PyPI і npm, на GitHub лише один сторонній репозиторій не про Minecraft. Loom = ткацький верстат:
плагін сплітає моди, конфіги і квести в одну збірку. Перегук із Fabric Loom свідомий і не шкодить, бо сфера та сама.

README, перший абзац (англійською): "packloom is a set of Claude Code skills that turn a Minecraft modpack into
plain text you can edit, build and verify with an agent: a mod list resolved against Modrinth, a server smoke test
that reads the crash log back to the agent, generated quest books and configs, and a keyboard map of every keybind.
No launcher of its own: it exports an .mrpack that Prism Launcher imports."

Рядок для резюме: "packloom: agent-driven Minecraft modpack editor as Claude Code skills (Python); resolves mods
via Modrinth, builds mrpack, verifies with a headless Forge server loop that feeds crash logs back to the agent."
Припущення: Артем правитиме назву або абзац, якщо не сподобається; обидва змінюються за хвилину.
